# 명리 검수 — 기운 케어 (energy_food / meeting_vibe) 자산·규칙

**일자:** 2026-06-18 · **대상 ADR:** ADR-040 §6.7(잠정 자산 검수) · **요청:** 사용자(Task 2)
**검수자:** Claude (AI 사전 검수 — 면허 명리 specialist 의 인간 사인오프를 대체하지 않음)
**상태:** 부분 PASS — 五味 매핑·분위기 아키타입은 고전 정합, pair-complement 합산 방식·식료 큐레이션은 **specialist 사인오프 대기(잠정 유지)**

본 검수는 두 자산의 *고전 정합성*과 *내부 논리 일관성*을 AI 가 확인할 수 있는 범위까지 검토한다. 응용
이론 선택(합산 방식 등)과 식료 적정성의 **최종 판정은 면허 명리/식료 전문가**가 내려야 한다(ADR-040 §6.7).

## 2. 항목별 판정

### 2.1 五行-五味 매핑 — PASS (고전 정합)

| 오행 | 코드의 맛 | 고전 五味 | 판정 |
|---|---|---|---|
| 목(木) | 신맛 | 酸 | ✅ |
| 화(火) | 쓴맛 | 苦 | ✅ |
| 토(土) | 단맛 | 甘 | ✅ |
| 금(金) | 매운맛 | 辛 | ✅ |
| 수(水) | 짠맛 | 鹹 | ✅ |

근거: 黃帝內經 素問·陰陽應象大論(오행배오미 木酸·火苦·土甘·金辛·水鹹). 5/5 표준 도식과 일치, 오류 없음.

### 2.2 보완 로직(맛→원소 보강) — PASS, 단 **하이브리드 성격 명기 필요**

규칙 사슬: *부족 오행 판정(명리/사주) → 그 오행의 맛 → 그 맛의 음식 → 해당 오행 기운 보강*.
- 마지막 고리(맛→오행 보강)는 명리 자체가 아니라 **黃帝內經 素問·宣明五氣篇 "五味所入"**(酸入肝/木·苦入心/火·甘入脾/土·辛入肺/金·鹹入腎/水)에 근거한 **食療** 도식이다.
- 따라서 이 기능은 **명리(오행 과부족 판정) + 食療(五味所入 보강)** 의 *교차 도메인 브리지*다. 내부적으로
  일관(부족 원소의 맛을 취해 그 원소를 보한다)되며 고전 근거가 있으나, **순수 명리 처방이 아님**을 자산
  주석/문서에 명기할 것을 권고(specialist 가 명리 단독으로 기대하면 오해 소지). → **권고 R-1**.

### 2.3 식료 큐레이션 — PASS(합리), 큐레이션 한계 명기

각 음식이 표방한 五味에 실제로 부합:
- 목/신맛: 매실·레몬·새콤한 나물무침·딸기 — 산미 ✅
- 화/쓴맛: 도라지·쌉쌀한 나물·커피·다크초콜릿 — 고미 ✅ (커피·다크초콜릿은 *현대 식품*, 고전 아님 — 큐레이션)
- 토/단맛: 단호박·고구마·대추·잡곡밥 — 감미 ✅ (대추=大棗 甘, 補脾 고전 정합)
- 금/매운맛: 마늘·생강·대파·매콤한 국물요리 — 신미 ✅ (생강=生薑·대파=蔥 辛, 發散 고전 정합)
- 수/짠맛: 미역국·굴·담백한 해산물·김 — 함미/해물 ✅ (鹹 補腎 도식 정합)

오류 없음. 의료 단정 문구 없음(ADR-038/banned-phrases 정합). 단 식재료 선택은 *학술 처방이 아닌 한국
친화 큐레이션*이므로 식료 전문가의 적정성 사인오프는 별건으로 잔존. → review_status `ai_pending_human` 유지.

### 2.4 만남 분위기 아키타입 — PASS (오행 본성 정합)

| 오행 | 아키타입 | 오행 본성 | 판정 |
|---|---|---|---|
| 목 | 초록·생기·식물·트인 | 生發(春·청) | ✅ |
| 화 | 햇살·활기·밝고 따뜻 | 炎上(夏·적·열) | ✅ |
| 토 | 아늑·안정·포근·머물기 | 中·안정 | ✅ |
| 금 | 깔끔·정돈·군더더기 없는·모던 | 收斂·肅(秋·백) | ✅ |
| 수 | 물가·잔잔·차분·흐르는 | 潤下(冬·흑) | ✅ |

추상 분위기만 사용(실제 지명·상호 0건) — §5 PII/위치 규칙 정합. 오행 상징과 일관.

### 2.5 공통 보완 원소 규칙(pair-complement) — **조건부 / specialist 판정 대기**

규칙: 두 사람 `ohaeng_weighted` 분포를 **합산 → 최소(가장 약한) 원소 = 공통 보완**. 동률 tie-break 고정 `목화토금수`.

- **방향성: 정합.** "둘 다 부족한 원소를 보해 중화를 꾀한다"는 **억부(抑扶)·중화(中和)** 이론과 일관하며,
  개인 용신의 중화 분기(`yongsin.ts`)를 미러한다.
- **specialist 가 판정해야 할 잠정 지점(고전 텍스트만으로 결정 불가 — 응용 설계 선택):**
  1. **합산 방식**: 두 분포의 *단순 합산 최소* 가 적정한가, 아니면 *각자 용신의 통합* 또는 *통관(通關)*(상극
     원소 사이를 매개하는 원소)이 더 타당한가. = 학파 판단.
  2. **신강약 미반영**: 규칙이 각 개인의 신강/신약을 반영하지 않는다. 엄밀히는 "부족 원소"가 항상 보강
     대상은 아니다(신강자는 설기, 신약자는 부조). 쌍-최소 단순화가 개인 균형과 충돌할 여지.
  3. **scale 혼용**: `pairComplementForCharts` 가 한쪽이라도 `ohaeng_weighted` 해소 실패 시 양쪽을
     `five_elements_counts`(표면 8자 카운트)로 통일 — weighted/표면 스케일 차로 결과 원소가 달라질 수
     있음(코드에 문서화됨).
  4. **tie-break**: 고정 `목화토금수`(상생 순)는 결정성 확보용이며 "동률 시 어느 부족 원소 우선"의 명리적
     근거는 없음. yongsin-겹침 2차 tie-break 은 의도적으로 연기됨.

→ **review_status `ai_pending_human` 유지.** 방향은 정합하나 합산 방식·신강약 반영은 면허 specialist 의
설계 승인 필요(ADR-040 §6.7 잠정 지위 유지가 정확).

## 3. 권고

- **R-1(경미, 문서):** 자산 주석/스펙에 "energy_food = 명리(오행 과부족) + 食療(五味所入) 하이브리드"임을
  명기 — specialist 검수 의뢰 시 순수 명리 처방으로 오해 방지. (이미 본 리포트에 명문화)
- **R-2(specialist 발주 항목):** ① pair-complement 합산 방식(합산-최소 vs 용신통합 vs 통관) ② 신강약 반영
  여부 ③ 식료 큐레이션 적정성 — 3건을 면허 전문가에게 의뢰. `docs/qa/myeongri_specialist_review_request.md`
  체크리스트에 본 3건 반영 권고.
- **review_status:** 자산 전체는 `ai_pending_human` 유지(보수적). 단 §2.1 五味 매핑 컴포넌트는 고전 검증
  완료로 본 리포트가 기록.

## 4. 한계 (정직성 명시)

본 검수는 五味 도식의 고전 일치와 자산 내부 논리 일관성을 AI 가 확인한 *사전 검수*다. 합산 방식 선택과
식료 적정성은 **응용 이론·임상 판단 영역**으로, 면허 명리/식료 전문가의 최종 사인오프를 대체하지 않는다.
ADR-040 §6.7 의 "잠정" 지위는 그대로 유효하다.
